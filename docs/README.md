# LearnWeave Documentation

LearnWeave is the current product name; **ZhiForge** is the former name retained in compatibility and historical references.

Current behavior is defined by the root README.md, DEMO.md, docs/HACKATHON_DEMO.md, and the current source tree.

The v0.2-* documents describe the earlier SelectionTranslator architecture and are retained as historical design references. They do not override the current LearnWeave product flow, naming, storage paths, connector model, or release process.

## Current product principles

1. Capture is separate from Discover.
2. Saved learning material enters Inbox before formal knowledge.
3. Knowledge remains linked to source Evidence.
4. AI task routing is independent from one-shot desktop actions.
5. Source type is stable; platform-specific behavior belongs to Connectors.
6. Secrets remain outside configuration files.
7. Existing ZhiForge data and credentials remain readable during the rename transition.
